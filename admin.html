ग्राहक Refund Requests — Main Admin Review

ग्राहक के Refund अनुरोधों की जाँच करें। Review / Approve / Reject के लिए 10–2000 अक्षरों का Admin audit note अनिवार्य है। Approval से पैसा नहीं भेजा जाता; Approved अनुरोध के बाद अलग Razorpay Full Refund प्रक्रिया चलानी होगी।

Refund requests लोड हो रही हैं…

Razorpay Full Refund — Main Admin

केवल verified Razorpay-paid booking के लिए पूरा refund। Backend immutable labour bill / approved legacy quote और cancellation-fee ledger से exact amount निकालेगा। Refund शुरू होते ही pending electrician payout hold होगा; refund processed होने पर ही booking और fee ledger reverse होंगे। Retry पर वही idempotency key इस्तेमाल होगी।

Booking Accounting Reconciliation — Main Admin

एक Booking ID डालकर verified collection/refund, Labour, Commission, Electrician payout, cancellation-fee ledger और posted wallet entries का read-only मिलान देखें। यह रिपोर्ट कोई payment, refund, wallet posting या payout update नहीं करती। सभी रकम integer paise से दिखाई जाती हैं।

रिपोर्ट देखने के लिए Booking UUID दर्ज करें।
