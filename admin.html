Razorpay Full Refund — Main Admin

केवल verified Razorpay-paid booking के लिए पूरा refund। Backend immutable labour bill / approved legacy quote और cancellation-fee ledger से exact amount निकालेगा। Refund शुरू होते ही pending electrician payout hold होगा; refund processed होने पर ही booking और fee ledger reverse होंगे। Retry पर वही idempotency key इस्तेमाल होगी।

Booking Accounting Reconciliation — Main Admin

GST Company Profile और Service Tax Rules — Main Admin

कंपनी GST में Registered होने की पुष्टि Main Admin ही करेगा। अभी Unregistered स्थिति में GST शून्य रहेगा। कोई दर अपने-आप लागू नहीं होगी। Registered करने से पहले GSTIN, supplier state और लागू tax नियम Accountant से सत्यापित करें।

Service / Labour / Materials GST Rule

Service Category Code और Service Code Master Catalogue के exact codes से भरें। Rate प्रतिशत में लिखें (उदाहरण 5.00); backend इसे basis points में सुरक्षित करेगा। Taxable नहीं होने पर दर 0 रखें।

GST / Tax Invoice / Credit Note रिपोर्ट

Master GST रिपोर्ट में टैक्स इनवॉइस, पूर्ण Refund Credit Notes और Gateway Fee GST अलग दिखेंगे।
